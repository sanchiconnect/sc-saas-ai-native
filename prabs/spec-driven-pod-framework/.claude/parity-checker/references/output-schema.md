# ParityChecker — Output Schema

**File produced:** `artifacts/release/parity-check-report.md`  
**Version:** 2.1.0

---

## Required Sections (in order)

### 1. Report Header

```markdown
# Parity Check Report
**Sprint:** {sprint_id}
**Generated:** {date} {time}
**Run Mode:** First-Run Elicitation | Diff Mode
**Config Files Used:**
  - Staging:    artifacts/release/env-config-staging.yaml
  - Production: artifacts/release/env-config-production.yaml
```

### 2. Parity Verdict Block

Must appear immediately after the header.

```markdown
## ✅ ENVIRONMENTS ALIGNED  |  ❌ CRITICAL DRIFT DETECTED

**Critical Drift Items:** {n} — {Gate 3 status: "Gate 3 BLOCKED" | "Gate 3 may proceed (zero critical drift)"}  
**Notable Drift Items:** {n} — require POD Lead acknowledgement  
**Expected Differences:** {n} — documented and accepted  
**Total Config Dimensions Checked:** {n}
```

### 3. Critical Drift Table (if count > 0)

```markdown

| # | Dimension | Config Key | Staging Value | Production Value | Rule | Resolution Required |
|---|-----------|-----------|--------------|-----------------|------|---------------------|
| 1 | Feature Flags | notifications_v2 | true | false | B3 | Enable flag in production before deployment |
```

If count = 0: include section header with "None detected. ✅"

If count = 0: "None detected. ✅"

If count = 0: "None identified."


---

## Config YAML Schema Invariants

`env-config-staging.yaml` and `env-config-production.yaml` must:
1. Use identical top-level key structure (any key present in one must be present in the other).
2. Never contain secret values — variable names and presence flags only.
3. Include `generated_at` and `sprint_id` fields.
4. Be stored at `artifacts/release/` — never committed to source control with actual values.

---

## Report Invariants

1. **Verdict block before all content** (after header only).
2. **Critical drift count in verdict must match row count** in Critical Drift Table.
3. **Every config field must appear in Full Config Diff** — no omissions.
4. **Every expected difference must include a rationale** — undocumented expected differences do not exist.
5. **Attestation block always present** regardless of verdict.
6. **Run mode must be declared** — ELICITATION or DIFF.
